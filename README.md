# Caso Expreso · Puente LogiSur → Expreso Andino

Challenge técnico de Geno Insights (Software Developer Junior).

Programa en Python que toma el export diario de remitos de **LogiSur** y carga
automáticamente en la API de **Expreso Andino** los envíos que viajan por ese
transporte, reemplazando la carga manual.

> 🚧 En construcción. El README completo (cómo correrlo, supuestos y mejoras para
> producción) se va a ir completando a medida que avance la solución.

## Estructura

```
data/   → export de remitos del día (entrada, tal como viene de LogiSur)
kit/    → API de prueba de Expreso Andino y su documentación (provistos por Geno, sin modificar)
```
